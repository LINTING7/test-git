# 员工管理系统

## 项目介绍
一个基于 Java Web 的员工管理系统，实现员工、部门、用户的增删改查。这是我的第一个完整后端项目，包含了从前端页面、后端逻辑到数据库设计的全部流程。

## 技术栈
- 后端：Java + Servlet + JSP
- 数据库：MySQL
- 服务器：Tomcat

## 功能
- 员工管理（增删改查）
- 部门管理（增删改查）
- 用户管理（登录、注册、权限）
- 数据统计（列表、分页）

## 如何运行
1. 下载代码到本地
2. 导入 MySQL 数据库（数据库脚本在 `src` 或根目录下）
3. 用 IDEA 或 Eclipse 打开项目
4. 配置 Tomcat 服务器
5. 启动服务器，访问 `http://localhost:8080/` 即可
